# Installation

Works the same way in Claude Code and in the Claude Desktop app.

## Install

```
/plugin marketplace add jonasgoderis/jonas-skills-marketplace
/plugin install claude-skills@jonas-skills-marketplace
```

## Update

After pulling in new skills or a version bump on the marketplace repo:

```
/plugin update
```

## Uninstall

```
/plugin uninstall claude-skills@jonas-skills-marketplace
```
